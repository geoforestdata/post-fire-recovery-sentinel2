# Data

Place here the two files generated by `01_build_dataset.R`:

- `sample_points.csv`: columns `dNBR`, `NBR_pre`, `NDVI_pre`, `NDVI_1`, `NDVI_2`,
  `NDVI_3`, `elevation`, `slope`, `lon`, `lat`.
- `raster_stack.tif`: multiband raster with the same variables (without `lon` and `lat`).

The fire perimeter (`fire_perimeter.gpkg`) is an input you provide; `composites/` is a cache.
